# Sol Fast Track Checker для Windows 10/11

Проверка токена Solana на скам по Ctrl+C. Копируешь контракт или ссылку (pump.fun, DexScreener, GMGN, Axiom,
Photon) — через 1–2 секунды в правом нижнем углу экрана появляется окно с проверкой безопасности, а через
несколько секунд то же окно дополняется глубокой проверкой. Это тот же полный отчёт, что делает бот
**Solana Fast Track VIP** ([@Solana_Fast_Track_bot](https://t.me/Solana_Fast_Track_bot)):

- оценка 0–100 и вердикт, цена и изменения, капитализация, ликвидность, держатели, возраст, кривая pump.fun;
- mint/freeze, блокировка ликвидности, топ-10, риски RugCheck, honeypot-расширения Token-2022;
- бандл в блоке запуска, снайперы в следующих 3 блоках и сколько они ещё держат;
- свежие кошельки в топ-10, связанные кошельки, история создателя;
- всё, что снижает оценку, и ссылки DexScreener / RugCheck / GMGN / Solscan.

Окно не забирает фокус (печатаешь дальше там, где был), закрывается само через 45 секунд; пока курсор на нём —
не закрывается, а если кликнул или листаешь — остаётся, пока не нажмёшь ✕.

## Установка

1. **[Скачай SolFastTrackChecker.exe](https://github.com/iwantamustang66/Solfasttrackcheckerforwindows10-11/releases/latest/download/SolFastTrackChecker.exe)**.
2. Запусти. Если Windows пишет «Система Windows защитила ваш компьютер» — нажми **Подробнее → Выполнить в любом
   случае** (у программы нет платной подписи).
3. Напиши боту [@Solana_Fast_Track_bot](https://t.me/Solana_Fast_Track_bot) команду **/desktop** (нужен VIP) —
   он пришлёт личный код `sftd1:…`. Вставь его в окно программы → **Сохранить и проверить**.
4. Готово: у часов появится значок-щит (если не видно — стрелка ^). Скопируй любой контракт.

Меню значка: пауза, последние проверки, тестовое окно, окно / уведомления Windows, звук, язык,
автозапуск, код подключения, выход.

Код личный — никому не показывай. Новый `/desktop` заменяет только твой код, у других всё работает как
работало. Код действует, пока активен VIP.

## Если что-то не так

- Окно не появляется — значок в трее → «Тестовое окно».
- Файлы программы: `%APPDATA%\SolFastTrackChecker\` — `config.json` (настройки и код), `reports\` (отчёты),
  `checker.log` (журнал — пришли его в поддержку бота).

## Сборка

GitHub Actions (`.github/workflows/build.yml`) собирает exe на Windows через PyInstaller, запускает самопроверку
(`SolFastTrackChecker.exe --selftest selftest.txt`: разбор ссылок, отчёт, настоящее окно с проверкой — видно ли
его и не забирает ли оно фокус, цветные эмодзи, уведомления Windows) и выкладывает релиз.
Из исходников: `pip install -r requirements.txt`, `python sol_checker.py`.
